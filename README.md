☆健康管理ツール

〇 概要

毎日の体調や内服した薬を記録するツールです。毎日記録をつけ、それを確認することで体調の変化に気づくことやや管理に役立てられることを目的に作りました。
初めて作成したWeb制作のポートフォリオ作品となります。未完成です。

〇 使用技術
- HTML5
- CSS3（使用予定）
- Java(ツール内）
- JavaScript(使用予定)(サイトの動的デザイン、エフェクト)

〇 工夫したポイント
- 冗長になりすぎないようにコードをまとめる、分割する
- 機能をシンプルにする

〇 学んだこと・今後実装予定のもの
- HTMLの基礎的なタグの使い方や、Javaのwhile・if・for文の使い方について実践的に学べました。
- 内服する薬名、時間をまとめて記録できるようにする
- 内服し忘れている薬があればリマインダーできるようにする
